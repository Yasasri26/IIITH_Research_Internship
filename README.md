\# Computer Vision Internship – YOLO Based Object Detection \& Video Processing



\## Overview

This repository documents a 5-week internship focused on Computer Vision, Video Processing, and Deep Learning using YOLO models. The work progresses from basic video frame extraction to object detection, dataset preparation, model training, and evaluation.



The project builds a complete pipeline for:

\- Extracting frames from videos

\- Performing object detection using YOLO

\- Reconstructing videos from frames

\- Training custom models

\- Evaluating model performance using metrics



\---



\## Week 1 – Video Processing \& Frame Extraction



\- Downloaded short videos using yt-dlp

\- Extracted frames using ffmpeg

\- Converted video into multiple images

\- Reconstructed video from frames (30 FPS)

\- Added audio to video using ffmpeg

\- Generated around 1800 images from video processing



Skills:

\- Video to image conversion

\- Frame rate control

\- Audio-video merging using ffmpeg



\---



\## Week 2 – Virtual Environment \& YOLO Setup



\- Created Python virtual environment using venv

\- Installed ultralytics package

\- Ran pre-trained YOLO models for object detection

\- Performed inference on images and videos



Skills:

\- Python environment setup

\- Installing ML libraries

\- Running pretrained YOLO models



\---



\## Week 3 – Object Detection Pipeline



\- Applied YOLO detection on multiple images

\- Converted detected images into video format

\- Added music/audio to output videos

\- Improved visualization of results



Skills:

\- Batch image processing

\- Video creation from images

\- Multimedia processing



\---



\## Week 4 – Metrics \& Dataset Understanding



\- Analyzed YOLO performance metrics in runs/detect folder

\- Studied precision-recall curves, F1 score, confusion matrix

\- Understood dataset YAML configuration files

\- Learned dataset structure and labeling format

\- Introduction to semantic segmentation



Skills:

\- Model evaluation

\- Dataset metadata understanding

\- Computer vision theory



\---



\## Week 5 – Custom Model Training \& Evaluation



\- Trained custom YOLO model

\- Evaluated model using precision, recall, F1 score

\- Generated confusion matrix and evaluation plots

\- Saved trained weights (best.pt, last.pt)

\- Performed inference on images and videos



Skills:

\- Model training

\- Performance evaluation

\- Deep learning workflow
